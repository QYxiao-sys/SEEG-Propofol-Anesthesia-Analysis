# SEEG-Propofol-Anesthesia-Analysis


## Overview

This repository contains MATLAB  scripts used for analyzing intracranial stereoelectroencephalography (SEEG) recordings during propofol anesthesia.

This pipeline is used to study the neural dynamics of the frontal lobe and the hippocampus related to the recovery of consciousness (ROC) during propofol anesthesia.


## Analyses included

- Power spectral density (PSD)
- Phase-amplitude coupling (PAC)
- Functional connectivity analysis
- Granger causality analysis
- Statistical analysis and visualization


## Data availability

Due to patient privacy and ethical restrictions, raw SEEG recordings are not publicly available.

Analysis scripts are provided to facilitate reproducibility.


## Software requirements

MATLAB R2020b

Toolboxes:
- EEGLAB
- FieldTrip
- MVGC Toolbox
